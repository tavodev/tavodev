## Selected projects

### [OLON](https://olon.mx)

Founder and Forward Deployed Engineer, since 2025.

I have a coffee bar, Hanami, and OLON started because I couldn't find a point of sale I liked for running it.

I built it around what I need behind the counter: to keep taking payments when the internet goes down and see how much I make on each drink, along with how much I sold.

I test it at Hanami first. Other coffee shops now pay to use the product too.

<a href="https://olon.mx"><img src="assets/olon.webp" alt="OLON website showing the point of sale checkout screen"></a>

### [agentsconfig](https://github.com/tavodev/agentsconfig)

Open source macOS app.

I use Claude Code and Codex every day. Setting up and reviewing agent configuration is part of my work, and agentsconfig grew out of that.

I brought global and per-project settings for Claude Code, Codex, Gemini CLI and other agents into one app. You can review and edit them in one place. The code is published under the MIT license.

### [Soji](https://github.com/tavodev/soji-releases)

A disk cleaner I shipped as a native macOS app, written in Swift. It includes automatic updates.

<a href="https://github.com/tavodev/soji-releases"><img src="assets/soji.webp" alt="Soji analyzing a Mac's disk"></a>

## How I work

I start by understanding how the business works and what it needs to solve. I decide the architecture and break the work into scoped tasks. I started with Python and Django in 2015 and was a Tech Lead before I worked with agents.

Today I build with Claude Code and Codex. I set up their instructions and permissions and review every change before publishing. I decide what reaches production.

Tools: Claude Code, Codex, MCP, hooks, skills, Python, Django, TypeScript, Swift, Flutter, C#, Lua, PostgreSQL, Docker and AWS.

### Open source

Alongside agentsconfig, I published these native macOS apps under the MIT license.

- [wports](https://github.com/tavodev/wports): Shows which ports are in use and lets you kill the process holding them. It comes with a CLI and an MCP server so agents can use it too.
- [repoyo](https://github.com/tavodev/repoyo): Lists your GitHub repos so you can change their visibility, archive them or delete them. It starts in simulation mode, and to actually delete a repo you have to type its full name.
